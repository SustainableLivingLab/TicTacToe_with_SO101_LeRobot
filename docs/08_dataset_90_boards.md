# 90-Episode Dataset Reference

All 90 board layouts for recording, generated by `board_generator.py` with
`seed=1`. 9 target cells, 10 demonstrations each. X = Blue, O = Red, . = empty,
target cell shown as `_` (leave empty, place a Red/O tile here during this demo).

Regenerate with:

```bash
python -m lerobot.scripts.ticTacToe.board_generator
```

(or import `TicTacToeGenerator` directly, see bottom of `board_generator.py`)
